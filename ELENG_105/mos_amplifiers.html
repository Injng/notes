1. Common Source Amplifier

We want to take some voltage input signal and get an amplified voltage output signal. However, we know that MOSFETs turn a voltage to current instead. In order to get a voltage output, we can pass that current through some resistor:

This topology is called a common source amplifier. Taking the drain current at saturation, equating that with the current through the resistor, and solving for \(V_{\text{out}}\), we get the following large signal relationship:

\begin{align} V_{\text{out}} = -R_D\left[\frac{1}{2}\mu_nC_{\text{ox}}\frac{W}{L}(V_{\text{in}}-V_T)^2\right]+V_{DD} \notag \end{align}

However, we want the small signal gain \(A_v\), so we have

\begin{align} A_v = \frac{\partial V_{\text{out}}}{\partial V_{\text{in}}} = -R_D\left[\mu_nC_{\text{ox}}\frac{W}{L}(V_{\text{in}}-V_T)\right] \notag \end{align}

Notice the part inside the brackets is just \(g_m\). Therefore, our small signal gain (ignoring channel length modulation) is:

\begin{align} \boxed{A_v = -g_mR_D} \end{align}

This result is also immediately apparent if we draw the small signal model, and realizing that \(R_D\) connects across drain and ground. We can use this technique to derive the small signal gain when we also consider channel length modulation:

Then, the small signal gain is:

\begin{align} \boxed{A_v = -g_m(R_D\parallel r_o) } \end{align}
