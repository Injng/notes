1. Continuous-Time Fourier Transform

The continuous-time Fourier transform, or CTFT, is for continuous-time aperiodic signals.

1.1. Synthesis and Analysis Equations

The synthesis equation for the CTFT is an integral of the frequency spectrum along with its corresponding frequencies:

\begin{align} \boxed{x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(\omega) e^{i\omega t}\text{ d}\omega} \end{align}

The analysis equation is:

\begin{align} \boxed{X(\omega) = \int_{-\infty}^{\infty} x(t) e^{-i\omega t}\text{ d}t} \end{align}

2. CTFT Properties

2.1. Time Shift Property

\(\require{mathtools}\) The time shift property states that if

\begin{align} x(t) \xleftrightarrow{\:\mathcal{F}} X(\omega) \notag \end{align}

then

\begin{align} x(t-t_0) \xleftrightarrow{\:\mathcal{F}} X(\omega)e^{-i\omega t_0} \end{align}

2.2. Frequency Shift Property

The frequency shift property states that if

\begin{align} x(t) \xleftrightarrow{\:\mathcal{F}} X(\omega) \notag \end{align}

then

\begin{align} x(t)e^{i\omega_0 t} \xleftrightarrow{\:\mathcal{F}} X(\omega - \omega_0) \end{align}

2.3. Convolution Property

The convolution property states that if

\begin{align} f(t) \xleftrightarrow{\:\mathcal{F}} F(\omega) \notag \end{align}

and

\begin{align} g(t) \xleftrightarrow{\:\mathcal{F}} G(\omega) \notag \end{align}

then

\begin{align} (f*g)(t) \xleftrightarrow{\:\mathcal{F}} F(\omega)G(\omega) \end{align}

2.4. Modulation Property

The modulation property states that if

\begin{align} x(t) \xleftrightarrow{\:\mathcal{F}} X(\omega) \notag \end{align}

and

\begin{align} c(t) \xleftrightarrow{\:\mathcal{F}} C(\omega) \notag \end{align}

then

\begin{align} x(t)c(t) \xleftrightarrow{\:\mathcal{F}} \frac{1}{2\pi}(X*C)(\omega) \end{align}

2.5. Differentiation Property

The differentation property states that if

\begin{align} x(t) \xleftrightarrow{\:\mathcal{F}} X(\omega) \notag \end{align}

then

\begin{align} \frac{\text{d}x(t)}{\text{d}t} \xleftrightarrow{\:\mathcal{F}} i\omega X(\omega) \end{align}

2.6. Conjugation and Conjugate Symmetry

The conjugation property states that if

\begin{align} x(t) \xleftrightarrow{\:\mathcal{F}} X(\omega) \notag \end{align}

then

\begin{align} x^*(t) \xleftrightarrow{\:\mathcal{F}} X^*(-\omega) \end{align}

If \(x(t)\) is real, then \(x(t) = x^*(t)\), and the conjugation property allows us to show that \(X(\omega)\) has conjugate symmetry:

\begin{align} X(-\omega) = X^*(\omega) \quad \text{if } x(t) \text{ real} \end{align}

3. CTFT for Periodic Signals

The CTFT was introduced for aperiodic signals, but we can also develop Fourier transform representations for periodic signals, thus allowing us to consider both periodic and aperiodic signals under one uniform context.

Generally, if \(X(\omega)\) is a linear combination of equally spaced impulses:

\begin{align} X(\omega) = \sum_{k=-\infty}^{\infty} 2\pi a_k \delta(\omega - k\omega_0) \notag \end{align}

Then applying the inverse transform relation yields the following signal:

\begin{align} x(t) = \sum_{k=-\infty}^{\infty} a_ke^{jk\omega_0 t} \notag \end{align}

Notice that this is just the Fourier series representation of a periodic signal! Thus, if we can represent a periodic signal with its Fourier series, then we know that its corresponding Fourier transform is a train of impulses occurring at some frequency.
